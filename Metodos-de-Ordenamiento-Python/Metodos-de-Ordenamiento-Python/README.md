# Métodos de Ordenamiento en Python

Este repositorio contiene nueve ejercicios desarrollados en Python: tres por cada método de ordenamiento.

## Estructura

- `Burbuja/`: ejercicios de ordenamiento por intercambio de elementos consecutivos.
- `Insercion/`: ejercicios que insertan cada elemento en su posición correcta.
- `Seleccion/`: ejercicios que seleccionan el elemento menor o mayor para colocarlo en su posición.

## Ejercicios

### Burbuja
1. Ordenar números de menor a mayor.
2. Ordenar calificaciones de menor a mayor.
3. Ordenar edades de menor a mayor.

### Inserción
1. Ordenar números enteros de menor a mayor.
2. Ordenar precios de menor a mayor.
3. Ordenar números de mayor a menor.

### Selección
1. Ordenar números de menor a mayor.
2. Ordenar calificaciones de mayor a menor.
3. Ordenar edades de menor a mayor.

## Requisitos

- Python 3.8 o superior.
- No se necesitan librerías externas.

## Ejecución

Desde una terminal, entra a la carpeta del ejercicio y ejecuta, por ejemplo:

```bash
python ejercicio1.py
```

## Complejidad

Los tres algoritmos tienen una complejidad temporal promedio de `O(n²)`. Inserción puede ejecutarse en `O(n)` cuando la lista ya está ordenada.
